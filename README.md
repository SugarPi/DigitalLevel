# ESP32 DigitalLevel
This is a basic digital level created using an ESP32-3C microcontroller and a GY521 accelerometer/gyroscope module. It displays precise angle readings on an OLED display and uses 4 directional LEDS for as a quick intuitive indicator to guide the user to the right angle (handy for leveling without staring at the screen). 

#Installation
First assemble the hardware using the schematic, then flash the ESP32 using the provided code on Arduino IDE. User must install the following libraries
- Adafruit BusIO by Adafruit
- Adafruit GFX Library by Adafruit
- Adafruit SSD1306 by Adafruit
- GY521 by Rob Tillart
